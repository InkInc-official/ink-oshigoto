# Ink Oshigoto

> **Ink Inc.** — AI Creation, Human Care. The Future Drawn Together.

応援してるあの人との歴史を記録する、あなただけの**推しごとノート**。「推し事」と「お仕事」、同じ音に込めた小さな言葉遊びから生まれました。

Ink Lanternの視点を反転させたツールです。Ink Lanternが「ライバーが視聴者を忘れないため」の手帖だったのに対し、Ink Oshigotoは**「視聴者が、応援してるライバーへの気遣い方を自分のために記録する」**ための手帖です。

---

## 特徴

- 🫙 インストール不要。`index.html` をブラウザで開くだけで動作
- 📱 スマホでの利用を前提としたモバイルファーストUI
- 🖼 推しの写真を登録可能（ブラウザ内で自動的に正方形へリサイズ・軽量化してから保存）
- 🩶 「出逢ってから〇〇日」を自動計算。推し歴が長くなるほど、円のインクの色が深くなっていく仕組み
- 🐾 複数の推しをタブで切り替えて管理可能
- ⚠️ NG事項・気をつけたい話題の記入欄あり（他の項目と見た目を分けて表示）
- 🔒 サーバー・アカウント登録は一切不要。データは自分のブラウザ内（localStorage）だけに保存

## 記録できる項目

1. 初めて出会った日
2. 推しの好きなこと（アーティスト・音楽・嗜好品など）
3. バッジ獲得記念日
4. 大きなギフトを送った日（あふおも等）
5. ライバーの誕生日
6. ライバーの初配信日
7. 弾幕記入欄
8. 自由記述欄（NG事項・気をつけたいこと）

## 使い方

1. このリポジトリをダウンロード（またはクローン）する
2. `index.html` をブラウザで開く
3. 「＋ 推しを追加」から、応援してる人を登録していく

## 自分のサイトとして公開する場合

`index.html`・`icon.svg`・`manifest.json`・各サイズのアイコンPNGを、GitHub PagesやNetlifyなど好きな静的サイトホスティングにそのまま置くだけで公開できます。ビルドツールや依存パッケージは一切不要です。

## PWA対応について

ホーム画面に追加することで、アプリのように起動できます。`manifest.json`によりアプリ名・テーマカラー・アイコンが定義済みです。

> Linux（Budgie環境等）でPWAインストール後にアイコンが反映されない場合は、GTKのアイコンキャッシュが古いままになっている可能性があります。以下のコマンドでキャッシュを再生成してください。
> ```bash
> gtk-update-icon-cache -f -t ~/.local/share/icons/hicolor
> ```

## データについて

すべてのデータはブラウザのlocalStorageに保存されます。

- 外部サーバーへの送信は一切ありません
- 写真データも同様に端末内保存のみで、外部には送信されません
- ブラウザのキャッシュ・サイトデータを削除するとすべてのデータが消えます
- 異なるブラウザ・デバイス間での同期はありません
- 推しの写真を複数登録すると、テキストのみのInk Lanternより保存容量を消費しやすい点にご留意ください（IRIAM文化圏では推しの数は多くて数名程度と想定されるため、通常利用では問題ない範囲です）
